# Projeto Grid — Clone do WhatsApp

Um clone da interface do WhatsApp com funcionalidade de troca de perfil, desenvolvido como projeto de estudo de HTML, CSS e JavaScript.

🔗 **Demo online:** [samuellacerdx.github.io/projeto-grid](https://samuellacerdx.github.io/projeto-grid/)

## ✨ Funcionalidades

- Interface inspirada no layout do WhatsApp Web
- Troca de perfil do usuário
- Layout responsivo construído com CSS Grid

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (Grid Layout)
- JavaScript

## 🚀 Como executar o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/SamuelLacerdx/projeto-grid.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd projeto-grid
   ```
3. Abra o arquivo `index.html` no seu navegador — não é necessário instalar nenhuma dependência.

## 📁 Estrutura do projeto

```
projeto-grid/
├── assets/       # Imagens, ícones e demais recursos estáticos
└── index.html    # Página principal da aplicação
```
